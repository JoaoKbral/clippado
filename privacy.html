Privacy Policy

Last updated: 2026-11-19

What is stored

  • OAuth tokens for the operator's own connected YouTube and TikTok accounts, plus the account's display name and id. They are stored only on the operator's computer and are used only to upload videos to those accounts.
  • Public live stream video and the public chat message count, used to choose and cut clips. Chat messages are not stored beyond a short rolling window.

Google and YouTube data

clipwatcher uses YouTube API Services. With the operator's permission it requests two Google scopes:

  • youtube.upload - to upload the clips to the operator's own YouTube channel;
  • youtube.readonly - to read that channel's name and id, so the operator can see which channel is connected and get the link of each uploaded video.

Nothing else is read from the Google account. The data is kept only on the operator's computer and is never sent to any server run by clipwatcher (there is none).

clipwatcher's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

By using clipwatcher with YouTube you are also bound by the YouTube Terms of Service and the Google Privacy Policy.

What is not done

  • No data is sold, shared with third parties, or used for advertising.
  • No data from other TikTok or YouTube users is collected.
  • This website has no cookies, analytics or tracking.

Deleting data

Revoke access from the platform's app settings at any time: for Google/YouTube at myaccount.google.com/connections; for TikTok in Settings → Security → Apps and services. Revoking makes the stored token useless; the operator deletes it from their computer on request, within 48 hours.
